# Advanced Robotics Project

Course material for **Advanced Robotics Project** (NBVHR1HBNF), an elective at Obuda University, Antal Bejczy Center for Intelligent Robotics (iRob). The course is taught in English in the autumn semester of 2026/27.

Instructors: Panna Zsoldos, Tamás Piricz.

## About the slides

The slides use the iRob BARK Beamer theme from [ABC-iRobotics/Beamer-template](https://github.com/ABC-iRobotics/Beamer-template). To rebuild the PDF, run `pdflatex` twice inside `week01_classical_robotics/slides/`; the README there has the details.

Some slides contain animations. They play in Adobe Acrobat Reader. Other PDF viewers show a still frame, and those slides have a "play in the browser" link that opens the animation as a GIF.

The photos come from Wikimedia Commons and are used under open licences. Authors, licences and sources are listed on the last slide and in `slides/img/web/CREDITS.md`.
